## 📋 معايير الصور

### الأبعاد المطلوبة
- **العرض**: 400-800 بكسل
- **الارتفاع**: 300-600 بكسل
- **النسبة**: 4:3 أو 16:9 مفضلة

### جودة الصور
- **الدقة**: عالية الجودة (HD)
- **الحجم**: أقل من 500KB لكل صورة
- **التنسيق**: PNG أو JPG

### التصميم
- **الخلفية**: شفافة أو متناسقة مع تصميم الموقع
- **الألوان**: متناسقة مع هوية المتجر
- **النص**: واضح ومقروء

## 🔄 تحديث الصور

عند إضافة صور جديدة:

1. **تسمية الملف**: استخدم اسماً وصفياً باللغة الإنجليزية
2. **التحسين**: ضغط الصورة لتقليل حجم الملف
3. **الاختبار**: تأكد من ظهور الصورة بشكل صحيح في الموقع
4. **التحديث**: حدث هذا الملف بمعلومات الصورة الجديدة
