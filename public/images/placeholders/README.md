# مجلد الصور البديلة (Placeholders)

هذا المجلد مخصص للصور البديلة التي تظهر عندما لا تتوفر الصورة الأصلية للمنتج.

## الملفات المطلوبة:

### 1. placeholder.jpg
- **الحجم**: 400x400 بكسل
- **التنسيق**: JPG أو PNG
- **الاستخدام**: صورة افتراضية للمنتجات
- **التصميم**: خلفية رمادية فاتحة مع أيقونة منتج بسيطة

### 2. product-placeholder.png
- **الحجم**: 400x400 بكسل
- **التنسيق**: PNG (مع شفافية)
- **الاستخدام**: صورة بديلة للمنتجات الجديدة
- **التصميم**: أيقونة منتج مع خلفية شفافة

### 3. loading-placeholder.svg
- **التنسيق**: SVG
- **الاستخدام**: أثناء تحميل الصور
- **التصميم**: رسم متحرك بسيط

## كيفية إنشاء صور بديلة:

2. **Figma**: تصميم مخصص
3. **Photoshop**: تصميم احترافي
4. **GIMP**: بديل مجاني لـ Photoshop

## أمثلة على التصاميم:

### للمنتجات الرقمية:
- خلفية متدرجة (رمادي فاتح إلى أبيض)
- أيقونة ملف أو مجلد
- نص "قريباً" أو "جاري التحضير"

### للاشتراكات:
- خلفية ملونة حسب نوع الخدمة
- أيقونة الخدمة (Netflix = أحمر، Spotify = أخضر)
- شعار مبسط

### للأدوات والبرامج:
- خلفية تقنية (خطوط أو شبكة)
- أيقونة أداة أو ترس
- ألوان تقنية (أزرق، رمادي)

## ملاحظات مهمة:

1. **الأداء**: استخدم صور محسّنة وصغيرة الحجم
2. **التوافق**: تأكد من عمل الصور على جميع المتصفحات
3. **الوضوح**: يجب أن تكون الصور واضحة على جميع الأحجام
4. **الاتساق**: حافظ على نفس الأسلوب لجميع الصور البديلة

## مسارات الاستخدام في الكود:
